# Floating Toolbar

The toolbar is a content UI injected on YouTube pages.

- Default: bottom-center, above the browser viewport/taskbar area.
- Draggable: drag the `CMJ` handle to any viewport location.
- Auto-hide: a small handle remains and the toolbar reveals when the pointer approaches the current position.
- Configurable: position, custom coordinates, reveal distance, scale, YouTube-only visibility and enable/disable.
- Actions: Target Feed, Scan, Ad Protection, Block Current Video, Shorts filter and Settings.

## 2.0.0 Data Boundary Note

Data Sync and database exports operate on the `database/` scope. Runtime YouTube Library and mode/profile snapshots are designed for portable synchronization, while generated Chrome `_metadata/` content is excluded.
