CHARLIE MJ YOUTUBE

About the Extension

Local-first YouTube content intelligence, learning profiles, library management and focused controls.

What it does

Charlie MJ YouTube organizes YouTube around your selected mode, country, language, professional profile and library. Decisions are designed to remain deterministic and explainable on your device.

Modes

  • General
  • Tech
  • Language Learning
  • Productivity
  • Custom

Unified language catalog

The same 7,000+ language master catalog is shared by Target Language, Tech Mode and Language Learning Mode. Country selection can suggest national/official languages while manual selection remains available.

YouTube Library

Save channels, playlists and videos with original YouTube metadata, profiles, categories and collections. Library data can be refreshed manually or automatically when records become stale.

Privacy-first design

No required backend or AI service is needed. Settings and library records are stored locally in Chrome storage. Optional GitHub synchronization remains user-controlled.
